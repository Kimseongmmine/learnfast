# 다시봄

공부 계획과 복습이 한 바퀴 도는 앱.

하루 계획을 짜주고, 배운 것을 다시 볼 때가 되면 **그 계획 안에 넣어줍니다.** 따로 복습 화면을 열 필요가 없습니다.

**API 키 없이도 전부 동작합니다.** 서버도, 계정도, 결제도 없습니다.

---

## 뭐가 다른가

**1. 다시 읽는 대신 안 보고 떠올리게 합니다**

개념·유도 과제는 계획에 이렇게 나옵니다:

```
09:00 ● 안 보고 써보기 — 정규화 1NF~3NF
       학교 도서관
```

교재를 덮고 백지에 써보고, 막히면 그때 엽니다. 코드를 짜는 과제에는 안 붙입니다 — 백지가 안 통하니까요.

**2. 틀린 것만 다시 뜹니다**

블록을 끝낼 때 한 줄만 묻습니다. 유형에 따라 `막혔던 지점?` `틀린 번호?` `막힌 단계?` `안 나온 것?`.

- **비우면** = 알았다 → 다음 차례가 멀어집니다 (1 → 2 → 4 → 8 → 16일)
- **적으면** = 틀렸다 → 내일 다시 나옵니다

개념·유도는 한 줄을 안 적어도 자동으로 큐에 들어갑니다. 타이핑을 한 번도 안 해도 복습이 돕니다.

**3. 무거운 건 여러분이 쓰는 AI가 합니다**

무료 API 한도를 쥐어짜는 대신, 앱이 **여러분 상황이 담긴 프롬프트를 만들어 클립보드에 복사**합니다. ChatGPT든 Gemini든 이미 쓰는 곳에 붙여넣고, 답을 다시 붙여넣으면 과제와 문제가 됩니다.

| 버튼 | 프롬프트에 담기는 것 |
|---|---|
| 과제 쪼개기 | 과목 · 범위 · 마감 → 60분짜리 과제 목록 |
| 오늘 인출 문제 | 오늘 복습할 항목 + 지난번 틀린 지점 |
| 막힘 — 다음 한 걸음만 | 지금 과제 + 전에 막혔던 곳 |
| 진도 점검 | 남은 날 · 범위 · 완료 개수 |

**API 쿼터 소비 0.** 키를 넣으면 하루 계획 정도는 자동으로 짜지만, 없어도 템플릿이 받습니다.

**4. 평가하지 않습니다**

칭찬도 위로도 잔소리도 없습니다. `착수 2/3 · 완료 1` 처럼 사실만 적습니다. 하지 않은 것을 한 것처럼 세지도 않습니다.

---

## 쓰는 법

**처음 한 번** — 열면 과목·시험 날짜·공부하는 곳을 묻습니다. 3분.

**매일 30초**
1. 아침에 `오늘 계획 생성`
2. 블록이 시작될 때 `시작` (±5분 안에)
3. 끝낼 때 한 줄 — 비우거나 채우거나

**복습이 뜨면** `✓ 기억났다` / `✗ 안 나왔다` 중 하나.

---

## 과목 팩 — 만든 걸 남에게 주기

목표 카드의  를 누르면 그 과목이 파일 하나로 나옵니다. 과제 목록과 복습 항목, 인출 문제까지.

**내 진도는 안 딸려갑니다.** 완료 여부·복습 상자·다음 차례·틀린 지점·공부한 시간은 전부 빠집니다.
받는 사람은 1번 상자부터 시작합니다. 남의 진도가 내 진도가 되면 안 되니까요.

같은 수업 듣는 사람끼리 한 번 만들어 돌리면 됩니다. 이미 그 과목을 하고 있으면 기존 목표에 얹히고, 같은 과제는 두 번 안 들어갑니다.

---

## 이 앱이 자기를 재는 방법

기록이 쌓이면 **기록 탭**에 실제 숫자가 뜹니다 — 복습 큐 항목 수, 굳은 것, 항목당 본 횟수, 인출 성공률, 핵심 착수율. 없는 숫자는 안 보여줍니다.

설계도 측정으로 정했습니다. 복습 간격 `[1,2,4,8,16]`은 15주 학기를 시뮬레이션해서 고른 값입니다. 벼락치기와 손대는 횟수를 같게 맞췄을 때:

| | 시험 당일 | 시험 2주 뒤 |
|---|---|---|
| 벼락치기 | 93.1 | 12.5 |
| 다시봄 | 94.0 | 88.7 |

**정직하게: 시험 하나만 보면 벼락치기와 거의 같습니다.** 차이는 2주 뒤에 납니다 — 기말과, 이 과목 위에 쌓이는 다음 과목에 남는 양입니다.

**안 되는 기능은 뺐습니다.** "배운 날 저녁에 한 번 더 보기"는 그럴듯했지만 재보니 회상이 91.3% → 85.4%로 떨어져서 넣지 않았습니다. 아직 잘 기억하는 걸 다시 보면 얻는 게 거의 없습니다.

---

## 데이터

**모든 것은 이 브라우저에만 저장됩니다.** 서버가 없고, 어떤 데이터도 밖으로 나가지 않습니다. 분석 도구도 안 붙였습니다.

그래서 **백업이 중요합니다.** 사파리는 7일간 안 들어가면 저장 데이터를 지우고, 기기 용량이 부족하면 브라우저가 통째로 비울 수 있습니다. 설정 탭의 `⬇ 백업 내보내기`를 가끔 눌러두세요. **API 키는 백업에 들어가지 않습니다.**

---

## 한계

- **PC 기준으로 만들었습니다.** 폰에서도 열리지만 블록을 끌어 옮기는 편집은 안 됩니다
- 기기 간 자동 동기화가 없습니다. 백업 파일로 옮깁니다
- 무료 AI 모델은 가끔 실패합니다 → 자동으로 고정 템플릿으로 넘어갑니다. 앱은 안 깨집니다
- 강제성은 착수 창(시작 ±5분)뿐입니다. 알림은 탭이 열려 있을 때만 뜹니다

## 실행

```
python -m http.server 8000
```
`http://localhost:8000`

빌드 도구도 의존성도 없습니다. 파일 네 개(`index.html` `app.js` `style.css` `manifest.json`)가 전부입니다.
